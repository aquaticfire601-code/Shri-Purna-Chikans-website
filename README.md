# Shri Purna Chikans Website

Official website for **Shri Purna Chikans** (Authentic Lucknowi Chikankari · Estd. 1994).

## How to Deploy to GitHub Pages:
1. Create a repository on GitHub (e.g. `shri-purna-chikans` or `<username>.github.io`).
2. Upload all files and the `images/` directory in this folder directly to the root of the repository.
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Source**, select the `main` (or `master`) branch and folder `/ (root)`.
5. Click **Save**. Your site will be live immediately!
